0はじめに（全体の流れ・部品・安全）

このガイドは、前回の「組み立てガイド」の続きです。ブレッドボードの上で、熱電対1本の温度が出ることは確認済みです。今回は、その回路をユニバーサル基板（穴あきの基板）に組み直して、ケースに入れます。

むずかしい言葉は使いません。1つの手順では、1つのことだけをします。手順ごとに「できたかの見分け方」「よくある失敗と直し方」「テスターで確かめる」「写真を送るポイント」を付けました。できたら、四角をタップしてチェックを入れてください。チェックはこの端末に残るので、あとで続きから始められます。

前回からの続きです（ここまでは済んでいます）
  • ブレッドボード版は、動作を確認した。
  • XIAO にアンテナとピンが付いていて、プログラムも書き込み済み。今回は書き込みません。
  • アンプ（MAX31855）の2枚目は、ピンが正しい向きにはんだ付けされている。これを使う。
  • 逆向きのアンプ1は、今回は使いません（予備）。
この基板は「片面」です。ランドは裏だけ

買った基板は片面です（70×50mm、穴 24×18）。銅の丸い「ランド」があるのは、裏だけです。部品は、表（ランドの無い面）から挿し、裏ではんだ付けします。裏から挿すと、はんだ付けできません。

できあがりの姿

下の2枚が完成図です。表は部品を挿す面、裏ははんだ付けする面です。穴の名前（C13 など）は、手順1で説明します。今は、「こういう形になる」と眺めるだけで大丈夫です。

全体の流れ

  1. 基板の基本：穴の数と取付穴を確かめる、表と裏、穴の名前、左右が反対になること（手順1。30分）
  2. 部品を挿してはんだ付け：抵抗 → LED → ボタン → ソケット（手順2。90分）
  3. 裏の配線：10本の線を1本ずつ（手順3。90〜120分）
  4. テスターで確認：電源を入れる前に（手順4。30分）
  5. モジュールを挿して動かす：XIAO とアンプを挿し、温度を見る（手順5。30分）
  6. ケースに入れる（手順6。印刷の時間は別）
  7. 困ったとき（手順7）

1日で終わらせなくても大丈夫です。どの手順の終わりでも、止めてかまいません。

はんだ付けの点数

はんだ付けは、全部で48点です。部品の足が28点（抵抗2、LED 2、ボタン4、XIAO のソケット14、アンプのソケット6）、線の端が20点（10本 × 2）です。

安全（先に読んでください）

やけどに注意
  • はんだごてのこて先は、約340℃になります。さわるとやけどをします。
  • 使わないときは、必ずこて台に置きます。机や手に直接置きません。
  • 作業の途中で、その場を離れないでください。終わったら電源を切り、コンセントを抜いて、20分ほど冷まします。
煙・手洗い・飛び散り
  • 換気をします。煙の真上に顔を近づけません。
  • はんだには鉛が入っているものがあります。作業中は飲食しません。作業のあとは手を洗います。
  • 足や線をニッパーで切ると、破片が飛びます。保護メガネがあると安心です。切るときは、破片を手でおおいます。
電源（USB）を入れるのは、手順4のあとだけ

手順4のテスターの確認が終わるまで、USB ケーブルを XIAO につながないでください。それまでの確認は、どれも「USB を抜いたまま」です。

テスター（サンワ PM3）の使い方

前回と同じです。つながっているかを、音で調べます。

  • 鳴り続ける ＝ つながっている。
  • 鳴らない ＝ つながっていない。
  • XIAO やアンプを挿したあとは、一瞬「ピッ」と鳴って止まることがあります。部品にたまる電気を測っているだけで、正常です。
写真を送るときのコツ

うまくいかないときは、写真を Claude に送ってください。明るい所で、真上から、ピントを合わせて撮ります。全体の写真と、気になる所に近づいた写真の2枚があると確実です。各手順の「写真を送るポイント」を見てください。

1ユニバーサル基板の基本（穴の数・取付穴・表と裏・穴の名前）
所要時間の目安　30分

最初に、基板の「穴の数と取付穴」「表と裏」「穴の名前」「左右が反対になること」を確かめて、覚えます。ここがあいまいだと、裏の配線で穴を間違えます。

表と裏（片面基板）

  • 表＝部品を挿す面。銅の部分は見えません（片面基板なので、銅は裏だけ）。
  • 裏＝はんだ付けする面。穴のまわりに、銅の丸いランドが1つずつ見えます。ランドどうしは、はじめはつながっていません。はんだや線でつなげたところだけが、つながります。
部品は、必ず表（ランドの無い面）から挿します

ランドは裏だけです。表から部品を挿し、裏ではんだ付けします。部品を裏から挿してしまうと、足がランドの無い面に出て、はんだ付けできません。ソケットも、抵抗も、LED も、ボタンも、同じです。

穴の名前の付け方

穴には、列の文字 ＋ 行の番号で名前を付けます。表から見て、USB-C を左にして考えます。

  • 列：左から A, B, C, … X（24列）。
  • 行：上（奥）から 1, 2, 3, … 18（18行）。
  • 左上の穴が A1、右下の穴が X18 です。四隅の穴（A1・X1・A18・X18）は、取付穴のそばなので、何も差しません（図の×印）。
  • 例：C13 は「左から3番目の列、上から13番目の行」。Q8 は「左から17番目の列（A=1, B=2, … Q=17）、上から8番目の行」。

表と裏で、左右が反対になる

基板を本のページをめくるようにひっくり返すと、左右が反対になります（上下は変わりません）。表の左上の A1 は、裏から見ると右上です。裏の図では、列の文字が右から左へ A, B, C…と並びます。

いちばん多い間違い

裏から見たまま、表の図の「左」を「裏の左」だと思ってしまうことです。裏の図は、必ず「裏から見た図」を見てください。このガイドの裏の図には、列の文字が右から左へ並んでいます。それが目印です。

基板に目印を付ける

基板に、穴の名前の目印を書きます。上のふち（1 行の上）と、左のふち（A 列の左）に、細く切ったマスキングテープを貼って、そこに書きます。四隅の取付穴にテープをかけません（取付穴は、角から約 2.5mm の所にあります）。

  1. できたかの見分け方長い辺が 24 穴、短い辺が 18 穴だった。四隅の近くに、大きめの取付穴が4つある。

    よくある失敗と直し方数が違う。そこで止めて、数と基板の写真を Claude に送ってください。この図の穴の名前が、全部ずれます。

    写真を送るポイント基板全体を真上から1枚。四隅の取付穴が写るように。

  2. できたかの見分け方取付穴の中心は、各辺から約 2.5mm。直径は 3.0mm くらい。最初の穴（A1 の位置）までは、約 5.79mm と約 3.41mm。ビスは、直径が 2.2mm 前後の穴なら M2、3mm 前後なら M2.6 を選びます。

    よくある失敗と直し方測った値が、書いてある値と 0.5mm 以上ちがう。ケースの柱の位置と、使えない穴（四隅）が変わります。測った値を Claude に送って、ケースの図面を直してもらってください。（この手順は、はんだ付けの前に済ませます）

    写真を送るポイント取付穴にノギスを当てた写真を1枚（角から穴の中心までが分かるように）。

  3. できたかの見分け方表は、穴だけが並んでいる。裏は、金色（銅）の丸が並んでいる。

    よくある失敗と直し方どちらか分からない。明るい所で、斜めから見ます。光る銅の丸が見えるほうが裏です。

    よくある失敗と直し方あとで、角が分からなくなった。表の A1 の角に印があれば、いつでも向きが分かります。

    よくある失敗と直し方テープが取付穴にかかる。幅を細くします。四隅の取付穴は、あけておきます。

    写真を送るポイント表のテープ。A1 の角を中心に真上から1枚。

  6. できたかの見分け方裏から見ると、上のテープの文字が右から左へ A, B, C … と並んでいる。

    よくある失敗と直し方文字が左から右に並んでしまった。ひっくり返す向きが違います（上下をひっくり返してしまった）。左右の向きで、ひっくり返し直します。

    写真を送るポイント裏のテープ。A1 の角を中心に真上から1枚。

    よくある失敗と直し方裏で Q8 が右寄りにある。列の文字の並びを見直します（右から左へ A, B, C …）。

2部品を挿す順番とはんだ付け
所要時間の目安　90分

部品は、背の低いものから順に挿します。低いものを先に付けると、基板を裏返したときに、ぐらつきません。

いつも「表から挿して、裏ではんだ付け」

片面基板なので、ランドは裏だけです。部品は表（ランドの無い面）から挿します。基板を裏返して、裏（ランドのある面）にはんだ付けします。

はんだ付けは、表から部品を差して、裏でランドと足にはんだ付けします。1点ずつ、同じやり方です。

はんだ付けの基本

  • こては340℃。こて先をふいて、ぴかっとした銀色にしてから使います。
  • こて先を、足とランドの両方に当てて2秒温めます。そこに、はんだを当てて溶かします。はんだが流れたら、はんだ → こての順に離します。全部で 3〜4 秒が目安です。
  • できあがりは、つやのある富士山の形。灰色でザラザラなら、温め直します。
  • 1点が終わるたびに、となりの穴と、はんだでつながっていないか見ます。

足を切る

抵抗・LED・ボタンの足は、はんだ付けのあとで、ニッパーで切ります。基板の裏から出る長さは、1.5mm 以下にします（ケースの底に当たるため）。切るときは、破片が飛ぶので、手でおおいます。

  1. できたかの見分け方こて先が温まって、糸はんだを当てるとすぐ溶ける。

    よくある失敗と直し方はんだが溶けない。温度が低すぎるか、こて先が汚れています。こて先をふきます。

(1) 抵抗 R1：F14 と C14

  1. できたかの見分け方抵抗が基板に付いて、F14 と C14 の穴に足が入っている。F14 と C14 の間に、穴が2つ（D14・E14）ある。

    よくある失敗と直し方足の間が合わない。F14 と C14 は、間に穴が2つある位置です。数え直します。

  2. できたかの見分け方2点とも、つやのある富士山の形。

    よくある失敗と直し方玉になった。温め直します。となりのランドにくっついた。吸取線で取ります。

    写真を送るポイント裏から、抵抗の2点を近づけて真上から1枚。

  3. できたかの見分け方足が短く切れている。

    よくある失敗と直し方切ったら、はんだにひびが入った。温め直して、はんだを足します。

    テスターで確かめる黒を F14、赤を C14。鳴らない（抵抗が入っているので、鳴らないのが正しい）。鳴り続けたら、2つの足が、はんだでつながっています。

    写真を送るポイント切ったあとの裏を、真上から1枚。

(2) LED：C16（長い足）と B16（短い足）

  1. できたかの見分け方長い足がどちらか、言える。

    よくある失敗と直し方どちらも同じ長さに見える。縁が平らな側が−です。それでも迷うなら、写真を送ってください。

  2. できたかの見分け方LED が基板に垂直に立っている。長い足が右（C16）、短い足が左（B16）。平らな縁が左側。

    よくある失敗と直し方向きが逆（長い足を B16 に挿した）。LED は逆向きだと光りません。いったん抜いて、挿し直します。

    写真を送るポイント表から、LED を真上から1枚。

  3. できたかの見分け方2点が、つやのある富士山の形。LED が傾いていない。

    よくある失敗と直し方傾いた。はんだを温めながら、LED を指でまっすぐに直します。

    テスターで確かめる黒を B16、赤を C16。鳴らない。（LED は、向きによって電気を通すので、鳴らないのが正常です。鳴り続けたら、はんだがつながっています）

    写真を送るポイント裏の2点を近づけて1枚。

(3) タクトスイッチ：G15、I15、G18、I18

  1. できたかの見分け方鳴る組が2つ見つかった（例：①−② と ③−④）。それが「同じ組」。

    よくある失敗と直し方鳴る組が1つも見つからない。ボタンを押しながら調べると、全部鳴ります。押さないで調べます。それでも鳴らない場合は、そのスイッチは使えません。

    テスターで確かめる黒と赤の棒を、足に当てる。6通り（①②、①③、①④、②③、②④、③④）を調べ、押さないとき鳴る組を2つ書き留める。

    写真を送るポイントスイッチを手にもって、足と番号が分かるように。

  2. できたかの見分け方スイッチが基板に付き、4本が穴に入った。ボタンが押せる。

線の経路について

被覆線は、他のはんだの山の上を通さないように、曲げ位置を決めてあります（むき出しの先が、他の山にふれてショートするのを防ぐため）。むき出しの先は、他のネットの山から 2mm 以上はなれます。始点と終点（つなぐ穴）は、設計データの10本と同じです。曲げ位置だけを足しました。

線の下ごしらえ

線の端を、山に付ける

  • 線の先を山にのせてから、こて先を、山と線の両方に当てます。山が溶けて、線の先をつつみます。
  • はんだが足りないときは、糸はんだを少しだけ足します。
  • 付けたら、3秒、動かさない。動かすと、はんだがザラザラになります。
  • むいた部分は、山の上にだけおさまるようにします。はみ出た銅が、となりの山にふれるとショートします。
  • こてを、すでに付けた線の被覆に当てないでください。被覆が溶けて、芯がむき出しになります。
