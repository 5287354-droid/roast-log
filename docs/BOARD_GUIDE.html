0はじめに（全体の流れ・部品・安全）

このガイドは、前回の「組み立てガイド」の続きです。ブレッドボードの上で、熱電対1本の温度が出ることは確認済みです。今回は、その回路をユニバーサル基板（穴あきの基板）に組み直して、ケースに入れます。

むずかしい言葉は使いません。1つの手順では、1つのことだけをします。手順ごとに「できたかの見分け方」「よくある失敗と直し方」「テスターで確かめる」「写真を送るポイント」を付けました。できたら、四角をタップしてチェックを入れてください。チェックはこの端末に残るので、あとで続きから始められます。

前回からの続きです（ここまでは済んでいます）
  • ブレッドボード版は、動作を確認した。
  • XIAO にアンテナとピンが付いていて、プログラムも書き込み済み。今回は書き込みません。
  • アンプ（MAX31855）の2枚目は、ピンが正しい向きにはんだ付けされている。これを使う。
  • 逆向きのアンプ1は、今回は使いません（予備）。

できあがりの姿

下の2枚が完成図です。表は部品を挿す面、裏ははんだ付けする面です。穴の名前（C14 など）は、手順1で説明します。今は、「こういう形になる」と眺めるだけで大丈夫です。

全体の流れ

  1. 基板の基本：表と裏、穴の名前、左右が反対になること（手順1。20分）
  2. 部品を挿してはんだ付け：抵抗 → LED → ボタン → ソケット（手順2。90分）
  3. 裏の配線：10本の線を1本ずつ（手順3。90〜120分）
  4. テスターで確認：電源を入れる前に（手順4。30分）
  5. モジュールを挿して動かす：XIAO とアンプを挿し、温度を見る（手順5。30分）
  6. ケースに入れる（手順6。印刷の時間は別）
  7. 困ったとき（手順7）

1日で終わらせなくても大丈夫です。どの手順の終わりでも、止めてかまいません。

はんだ付けの点数

はんだ付けは、全部で48点です。部品の足が28点（抵抗2、LED 2、ボタン4、XIAO のソケット14、アンプのソケット6）、線の端が20点（10本 × 2）です。

安全（先に読んでください）

やけどに注意
  • はんだごてのこて先は、約340℃になります。さわるとやけどをします。
  • 使わないときは、必ずこて台に置きます。机や手に直接置きません。
  • 作業の途中で、その場を離れないでください。終わったら電源を切り、コンセントを抜いて、20分ほど冷まします。
煙・手洗い・飛び散り
  • 換気をします。煙の真上に顔を近づけません。
  • はんだには鉛が入っているものがあります。作業中は飲食しません。作業のあとは手を洗います。
  • 足や線をニッパーで切ると、破片が飛びます。保護メガネがあると安心です。切るときは、破片を手でおおいます。
電源（USB）を入れるのは、手順4のあとだけ

手順4のテスターの確認が終わるまで、USB ケーブルを XIAO につながないでください。それまでの確認は、どれも「USB を抜いたまま」です。

テスター（サンワ PM3）の使い方

前回と同じです。つながっているかを、音で調べます。

  • 鳴り続ける ＝ つながっている。
  • 鳴らない ＝ つながっていない。
  • XIAO やアンプを挿したあとは、一瞬「ピッ」と鳴って止まることがあります。部品にたまる電気を測っているだけで、正常です。
写真を送るときのコツ

うまくいかないときは、写真を Claude に送ってください。明るい所で、真上から、ピントを合わせて撮ります。全体の写真と、気になる所に近づいた写真の2枚があると確実です。各手順の「写真を送るポイント」を見てください。

1ユニバーサル基板の基本（表・裏・穴の名前）
所要時間の目安　20分

最初に、基板の「表と裏」「穴の名前」「左右が反対になること」を覚えます。ここがあいまいだと、裏の配線で穴を間違えます。

表と裏

  • 表＝部品を挿す面。銅の部分は見えません。
  • 裏＝はんだ付けする面。穴のまわりに、銅の丸いランドが1つずつ見えます。ランドどうしは、はじめはつながっていません。はんだや線でつなげたところだけが、つながります。

穴の名前の付け方

穴には、列の文字 ＋ 行の番号で名前を付けます。表から見て、USB-C を左にして考えます。

  • 列：左から A, B, C, … Z, AA, AB（28列）。
  • 行：上（奥）から 1, 2, 3, … 18（18行）。
  • 左上の穴が A1、右下の穴が AB18 です。
  • 例：C14 は「左から3番目の列、上から14番目の行」。Q11 は「左から17番目の列（A=1, B=2, … Q=17）、上から11番目の行」。

表と裏で、左右が反対になる

基板を本のページをめくるようにひっくり返すと、左右が反対になります（上下は変わりません）。表の左上の A1 は、裏から見ると右上です。裏の図では、列の文字が右から左へ A, B, C…と並びます。

いちばん多い間違い

裏から見たまま、表の図の「左」を「裏の左」だと思ってしまうことです。裏の図は、必ず「裏から見た図」を見てください。このガイドの裏の図には、列の文字が右から左へ並んでいます。それが目印です。

基板に目印を付ける

基板に、穴の名前の目印を書きます。いちばん外側の列と行（A 列、AB 列、1 行、18 行）には、何も差しません。その上に、細く切ったマスキングテープを貼って、そこに書きます。

  1. できたかの見分け方長い辺が 28 穴、短い辺が 18 穴だった。四隅の近くに、大きめの取付穴が4つある。

    よくある失敗と直し方数が違う。そこで止めて、数と基板の型番を Claude に送ってください。この図の穴の名前が、全部ずれます。

    写真を送るポイント基板全体を真上から1枚。四隅の取付穴が写るように。

  2. できたかの見分け方表は、穴だけが並んでいる。裏は、金色（銅）の丸が並んでいる。

    よくある失敗と直し方どちらか分からない。明るい所で、斜めから見ます。光る銅の丸が見えるほうが裏です。

  3. できたかの見分け方左上に A1 と書いてある。

    よくある失敗と直し方あとで、角が分からなくなった。表の A1 の角に印があれば、いつでも向きが分かります。

  4. できたかの見分け方上のテープに A, B, C … と書いてある。左のテープに 1, 2, 3 … と書いてある。全部書くのが大変なら、5つおき（E, J, O, T, Y と、5, 10, 15）でかまいません。

    よくある失敗と直し方テープが取付穴（B2）にかかる。幅を細くします。B 列と 2 行は、空けておきます。

    写真を送るポイント表のテープ。A1 の角を中心に真上から1枚。

  5. できたかの見分け方裏から見ると、上のテープの文字が右から左へ A, B, C … と並んでいる。

    よくある失敗と直し方文字が左から右に並んでしまった。ひっくり返す向きが違います（上下をひっくり返してしまった）。左右の向きで、ひっくり返し直します。

    写真を送るポイント裏のテープ。A1 の角を中心に真上から1枚。

  6. できたかの見分け方表と裏で、同じ穴（紙を透かして見たときに重なる穴）を指せた。裏では、C14 は右寄り、Q11 は左寄り。

    よくある失敗と直し方裏で Q11 が右寄りにある。列の文字の並びを見直します（右から左へ A, B, C …）。

目印は、完成したらはがします

ケースの中で基板のふちを受ける段があります。テープが厚いと合わなくなります。ケースに入れる前に、はがしてください（手順6）。

はんだ付けは、表から部品を差して、裏でランドと足にはんだ付けします。1点ずつ、同じやり方です。

はんだ付けの基本

  • こては340℃。こて先をふいて、ぴかっとした銀色にしてから使います。
  • こて先を、足とランドの両方に当てて2秒温めます。そこに、はんだを当てて溶かします。はんだが流れたら、はんだ → こての順に離します。全部で 3〜4 秒が目安です。
  • できあがりは、つやのある富士山の形。灰色でザラザラなら、温め直します。
  • 1点が終わるたびに、となりの穴と、はんだでつながっていないか見ます。

足を切る

抵抗・LED・ボタンの足は、はんだ付けのあとで、ニッパーで切ります。基板の裏から出る長さは、1.5mm 以下にします（ケースの底に当たるため）。切るときは、破片が飛ぶので、手でおおいます。

  1. できたかの見分け方こて先が温まって、糸はんだを当てるとすぐ溶ける。

    よくある失敗と直し方はんだが溶けない。温度が低すぎるか、こて先が汚れています。こて先をふきます。

(1) 抵抗 R1：F15 と J15

  1. できたかの見分け方抵抗が基板に付いて、F15 と J15 の穴に足が入っている。F15 と J15 の間に、穴が3つ（G15・H15・I15）ある。

    よくある失敗と直し方足の間が合わない。F15 と J15 は、間に穴が3つある位置です。数え直します。

  2. できたかの見分け方2点とも、つやのある富士山の形。

    よくある失敗と直し方玉になった。温め直します。となりのランドにくっついた。吸取線で取ります。

    写真を送るポイント裏から、抵抗の2点を近づけて真上から1枚。

  3. できたかの見分け方足が短く切れている。

    よくある失敗と直し方切ったら、はんだにひびが入った。温め直して、はんだを足します。

    テスターで確かめる黒を F15、赤を J15。鳴らない（抵抗が入っているので、鳴らないのが正しい）。鳴り続けたら、2つの足が、はんだでつながっています。

    写真を送るポイント切ったあとの裏を、真上から1枚。

(2) LED：L13（長い足）と L12（短い足）

  1. できたかの見分け方長い足がどちらか、言える。

    よくある失敗と直し方どちらも同じ長さに見える。縁が平らな側が−です。それでも迷うなら、写真を送ってください。

  2. できたかの見分け方LED が基板に垂直に立っている。長い足が手前（下）、短い足が奥（上）。平らな縁が奥側。

    よくある失敗と直し方向きが逆（長い足を L12 に挿した）。LED は逆向きだと光りません。いったん抜いて、挿し直します。

    写真を送るポイント表から、LED を真上から1枚。

  3. できたかの見分け方2点が、つやのある富士山の形。LED が傾いていない。

    よくある失敗と直し方傾いた。はんだを温めながら、LED を指でまっすぐに直します。

    テスターで確かめる黒を L12、赤を L13。鳴らない。（LED は、向きによって電気を通すので、鳴らないのが正常です。鳴り続けたら、はんだがつながっています）

    写真を送るポイント裏の2点を近づけて1枚。

(3) タクトスイッチ：O15、O17、R15、R17

  1. できたかの見分け方鳴る組が2つ見つかった（例：①−② と ③−④）。それが「同じ組」。

    よくある失敗と直し方鳴る組が1つも見つからない。ボタンを押しながら調べると、全部鳴ります。押さないで調べます。それでも鳴らない場合は、そのスイッチは使えません。

    テスターで確かめる黒と赤の棒を、足に当てる。6通り（①②、①③、①④、②③、②④、③④）を調べ、押さないとき鳴る組を2つ書き留める。

    写真を送るポイントスイッチを手にもって、足と番号が分かるように。

  2. できたかの見分け方スイッチが基板に付き、4本が穴に入った。ボタンが押せる。

    よくある失敗と直し方足が入らない。足を、ラジオペンチで少しだけ曲げます。無理に押し込まないでください。

  3. できたかの見分け方4点が、つやのある富士山の形。

    よくある失敗と直し方傾いている。はんだを温めて、指でまっすぐに直します。

    テスターで確かめるO15−O17 は鳴り続ける（同じ組）。R15−R17 も鳴り続ける。O17−R17 は、ボタンを押さないと鳴らない。ボタンを押すと鳴る。

    写真を送るポイント裏の4点を近づけて1枚。

(4) XIAO のソケット：B8〜H8 と B14〜H14

ソケットは、XIAO を挿したままはんだ付けします

ソケットだけをはんだ付けすると、少しずつ曲がって、XIAO が挿さなくなります。XIAO を挿して位置をそろえてから、はんだ付けします。ただし、XIAO に熱を伝えすぎないようにします。1点は3秒以内。続けて同じ列を温めず、列を行き来しながら付けます。

  1. できたかの見分け方7つの穴が並んだ黒いソケットが、2本、平行に並んでいる。ソケットが基板に付いている。

    よくある失敗と直し方ソケットが浮いている。基板の穴に、まっすぐ入っていません。押し込みます。

  2. できたかの見分け方XIAO が2本のソケットに、まっすぐ入った。奥の列が、左から 5V, GND, 3V3, D10, D9, D8, D7。

    よくある失敗と直し方USB-C が右になっている。向きが逆です。抜いて、180度回して挿し直します。

    写真を送るポイント表から、XIAO を真上から1枚（向きが分かるように）。

  3. できたかの見分け方基板が安定して、動かない。XIAO が机や台にふれていない。

    よくある失敗と直し方ぐらつく。台を、基板の四隅の近くに置き直します。

  4. できたかの見分け方2点が付いて、XIAO が基板と平行。

    よくある失敗と直し方傾いている。その点を温め直して、XIAO を指で押しながらまっすぐにします。

    写真を送るポイント横から、XIAO の傾きが分かるように1枚。

6ケースに入れる

印刷

  • 印刷時間の目安：本体 3〜4 時間、ふた 1.5〜2 時間（見積もりです）。
  • 最初の1回は、本体だけ印刷して、基板と部品を入れて合うかを確かめます。

寸法が合わないときは

部品の寸法は、仮の値です。入らない・ゆるい・穴の位置が合わないときは、実物を測って、その値を Claude に送ってください。STL を直してもらえます。測る場所の例：

測るものどこを
基板の外形・厚さ・取付穴の直径と位置角から角まで。取付穴は、基板の端から穴の中心まで
丸ピンソケットの高さ基板の面から、ソケットの上面まで（仮の値 8.5mm）
アンプのネジ端子台の高さアンプの基板の上面から、端子台の一番上まで（仮の値 10mm）。ケースの高さを決めます
USB-C ケーブルのプラグの根元（樹脂）の幅と高さ実際に使うケーブルを測る（仮の値 12×7mm）
熱電対の線の太さ被覆の上から（仮の値 3mm）
LED の高さ・ボタンの高さ基板の上面から頭まで

7困ったとき

困ったときは、まずUSB を抜いてから、見直します。あわてなくて大丈夫です。

症状考えられることやってみること
手順4で、3V3 と GND が鳴り続けるはんだのブリッジ。線のむき出しの先が、となりの山にふれたUSB をつながない。C8・D8 のまわり、アンプの Vin・GND（Q7・Q9）、線 5 と 7 のむき出しの先を、ルーペで見る。吸取線で直す。
手順4で、となりどうしが鳴るソケットの足のあいだに、はんだの橋その2つの穴に、吸取線をのせて、上からこてを当てる。吸い取れたら、もう一度調べる。
手順4 の表 A で、鳴らない線がある線の端が付いていない。山と線のあいだに、被覆が入ったその線の、両端を温め直す。被覆を 5mm むいてあるか見る。
ボタンを押さなくても、D5 と GND が鳴るスイッチの足を、組み違えた手順2-8 をやり直す。鳴る2本（同じ組）を、同じ列に差し直す。
ボタンを押しても、D5 と GND が鳴らないスイッチの足の組が、列に合っていない（組が、行にそって並んでいる）スイッチを、90度回して差す。または、別の向きのスイッチを使う。
USB をつないでも、何も光らないケーブルが充電専用。XIAO が深く入っていないデータ通信できるケーブルに替える。XIAO を、いったん抜いて、まっすぐ挿し直す。
XIAO が熱い・においがするショート。アンプを逆に挿したすぐに USB を抜く。アンプのネジ端子が右か確かめる。手順4をやり直す。
http://roast.local が開かないXIAO が家の Wi-Fi につながっていない。スマホが別の Wi-FiLED が「点灯」か見る。スマホを、同じ Wi-Fi にする。ボタンを短く押してから、60秒以内に http://roast.local/wifi。

「断線」と出る熱電対が付いていない。ネジ端子が締まっていないネジを締める。被覆をはさんでいないか見る。線が切れていないか、テスターで、線の両端を調べる。
「GND短絡」と出る熱電対の先が、金属にふれている。接地型先が、ドラム・網にふれていないか。非接地型か、前回のガイドの方法で確かめる。
つまむと、温度が下がる＋と−が逆ネジ端子で、2本の線を入れかえる。
