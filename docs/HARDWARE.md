# 温度計の組み立て（配線・はんだ付け・熱電対）

焙煎記録ノートの温度計は、**XIAO ESP32C3**（マイコン）と、熱電対の温度アンプ基板を 1〜3 枚つないで作ります。
アンプは **MAX31855（Adafruit #269 または互換品）が試作の標準**です。MAX31856（Adafruit #3263）でも作れます（後半に配線を載せます）。

- 熱電対は K 型を 1〜3 本。太さ・長さ・差し込む位置は使う人が決めます。ファームもアプリもそれに依存しません
- ファームの書き込みは、パソコンの Chrome で `docs/flash/index.html`（公開ページ）を開いて「書き込む」を押すだけです

---

## 1. 用意するもの

| もの | 数 | メモ |
|---|---|---|
| Seeed XIAO ESP32C3 | 1 | 技適済み。USB-C |
| Adafruit MAX31855 基板（#269）または互換品 | 熱電対の本数（1〜3） | **3.3V で動くもの**（下の注意を参照） |
| K 型熱電対（**非接地型**） | 1〜3 | MAX31855 では非接地型が必須 |
| ブレッドボード（ハーフ）・ジャンパ線（オス〜オス） | 1 式 | |

## 2. 配線（MAX31855 版・標準）

3 枚のアンプは **SPI のクロック（CLK）とデータ（DO）を共有**し、**CS（チップ選択）だけを 1 枚ずつ別の線**にします。
MAX31855 は読み取り専用なので **MOSI（D10）は使いません**。

### 2.1 配線表

| XIAO ESP32C3 | GPIO | → | アンプ #1（CH1・豆温度） | アンプ #2（CH2・排気） | アンプ #3（CH3・外気など） |
|---|---|---|---|---|---|
| **3V3** | — | → | Vin | Vin | Vin |
| **GND** | — | → | GND | GND | GND |
| **D8**（SCK） | GPIO8 | → | CLK | CLK | CLK |
| **D9**（MISO） | GPIO9 | → | DO | DO | DO |
| **D1** | GPIO3 | → | **CS** | — | — |
| **D2** | GPIO4 | → | — | **CS** | — |
| **D3** | GPIO5 | → | — | — | **CS** |
| D4 | GPIO6 | → | 状態 LED（+ 330Ω → GND） | | |
| D5 | GPIO7 | → | 押しボタン（もう片方を GND へ） | | |

- アンプの **3Vo は何もつなぎません**（基板の中で作った 3.3V が出てくる端子です）
- 熱電対が 1 本なら #1 だけ、2 本なら #1 と #2 をつなぎます。使わない CS の線はつながなくてかまいません
- XIAO の **5V 端子にはつながない**でください（アンプの DO が 5V になると XIAO を傷めることがあります。Vin は 3V3 から取ります）
- XIAO の基板の BOOT ボタンは D9（MISO）と同じ線です。**動作中に押すと読み取りがおかしくなる**ので、リセット用のボタンは外付け（D5）にしています

### 2.2 ブレッドボードの配置図

### 2.3 互換モジュール（Amazon などの安い MAX31855 基板）の注意

- **3.3V で動くか**を必ず確かめる。基板にレギュレータが載っていて「Vin 3〜5V」と書いてあるもの、または「3.3V 動作」と書いてあるものを選ぶ。5V 専用の基板は使えない
- ピンの名前が `SO`（= DO）、`SCK`（= CLK）、`VCC`（= Vin）のように違うことがある
- **偽物の MAX31855** が出回っています。届いたら、まず熱電対をつながずに電源を入れ、診断画面で **「断線」（OC）** と表示されること、熱電対をつないで **室温（20〜30℃）** が出ることを確かめてください。どちらかがおかしければ使わない
- 熱電対の線を差し込む端子が `T+` `T−` ではなく `+` `−` だけのことがある

## 3. 配線（MAX31856 版）

| XIAO ESP32C3 | GPIO | → | MAX31856 #1 / #2 / #3 |
|---|---|---|---|
| 3V3 | — | → | Vin（3 枚とも） |
| GND | — | → | GND（3 枚とも） |
| D8（SCK） | GPIO8 | → | SCK（共有） |
| D9（MISO） | GPIO9 | → | SDO（共有） |
| **D10（MOSI）** | GPIO10 | → | **SDI（共有。MAX31856 では必要）** |
| D1 / D2 / D3 | GPIO3 / 4 / 5 | → | CS（#1 / #2 / #3 に 1 本ずつ） |

- FLT と DRDY はつなぎません（ファームはレジスタを読んで判断します）
- 書き込むときは書き込みページで「MAX31856」を選んでください（PlatformIO なら `pio run -e xiao_c3_31856`）
- ESP32 DevKitC で作るときのピンは `firmware/include/pins.h` を見てください（SCK=18、MISO=19、MOSI=23、CS=5/17/16）

## 4. はんだ付け（初めての人向け）

アンプ基板と XIAO には、ピンヘッダ（足）を自分で付ける必要があります。

1. **こての温度は 340℃** くらいにします（鉛フリーはんだなら 350〜370℃）。熱すぎると基板のパターンがはがれます
2. **ピンヘッダをブレッドボードに差してから、その上に基板を載せて付けます**。これでピンがまっすぐに立ちます（長い方の足をブレッドボードに差す）
3. まず **両端の 2 本だけ** 付けて、基板が傾いていないか見ます。傾いていたら、そのピンを温め直してまっすぐにします
4. 残りのピンを付けます。こて先をピンと基板の穴（ランド）の両方に 1〜2 秒当ててから、はんだを当てて溶かし、はんだが流れたらはんだ → こての順に離します。全部で 3〜4 秒が目安
5. できあがりは **富士山のような形**（ピンのまわりに円すい状に広がり、つやがある）。丸い玉になっていたら温め直します
6. 最後に **ブリッジ（となりのピンとはんだがつながっている）** がないか、明るいところで横から見て確かめます。つながっていたら、はんだ吸取線を当てて上からこてで温めて吸い取ります
7. 熱電対はネジ端子に差し込んでドライバーで締めるだけなので、はんだ付けはいりません

## 5. 熱電対

### 5.1 非接地型を使う（MAX31855 では必須）

熱電対の先端（2 本の線を溶接した点）が、**金属のさや（シース）とつながっていないもの**を「非接地型」と言います。

- MAX31855 は、熱電対の線が GND（金属のドラムや手網の網など、アースにつながった金属）に触れると **「GND 短絡」（SCG）** の故障になったり、値が飛んだりします
- 先端の線がむき出しの熱電対は、**先端が金属（ドラム・網・ヒーター）に触れないように**取り付けてください
- **テスターで確かめる方法**: テスターを導通（ブザー）か抵抗（Ω）にして、片方の棒を**シース（金属のさや）**、もう片方を**熱電対の線の片方**に当てます。もう片方の線でも同じようにします
  - どちらの線でも **鳴らない（抵抗が無限大＝OL）** → 非接地型。使えます
  - **鳴る（数Ω）** → 接地型。MAX31855 では使えません（MAX31856 なら動くことが多いですが、おすすめはしません）
  - 2 本の線どうしは、つながっている（数Ω〜数十Ω）のが正常です。つながっていなければ断線しています

### 5.2 線の色と＋−（つなぐ向き）

熱電対の線の色は、**規格によって違います**。逆につなぐと、**温度が上がると表示が下がります**。

| 規格 | ＋（クロメル） | −（アルメル） |
|---|---|---|
| ANSI（アメリカ。Amazon の安い品に多い） | **黄** | **赤** |
| JIS（日本の旧色） | **赤** | **白** |
| IEC（国際・日本の新色） | **緑** | **白** |

- 「赤」が ANSI ではマイナス、JIS ではプラスです。**色だけで決めない**でください
- **磁石で確かめる方法**: K 型の **− 側（アルメル）は磁石に付きます**。＋側（クロメル）は付きません。冷蔵庫の磁石などを近づけてみてください
- アンプのネジ端子の **＋** にクロメル（磁石に付かない方）、**−** にアルメル（磁石に付く方）をつなぎます
- **アプリの診断画面で確かめられます**: プローブの先を指でつまむと、温度が上がれば正しい向きです。下がったら＋−が逆なので入れ替えてください。熱電対を外すと「断線」と出ることも確かめられます

## 6. 安全上の注意

- **本体（XIAO・アンプ基板・ブレッドボード・USB ケーブル）は炎や焙煎機の熱から離して**置いてください。熱に耐えるのは熱電対の先（シース）と耐熱の線だけです。基板は 85℃を超えると壊れたり、温度がずれたりします（「基板温度異常」と表示されます）
- 熱電対の線のうち、耐熱の被覆（ガラス繊維など）でない部分を火に近づけないでください
- 手網で使うときは、振っても線が引っ張られないように、線に余裕を持たせて固定してください
- 焙煎中は電源（USB）を抜かないでください。抜いてもアプリ側の記録は残りますが、抜いている間の温度は記録されません
- 子どもの手の届かない場所で使ってください

## 7. 組み立てたあとの確認（診断画面）

1. 書き込みページでファームを書き込む（`docs/flash/`）
2. スマホを `RoastLog-XXXX` の Wi-Fi につなぎ、`http://192.168.4.1` を開く
3. 機器の診断画面で:
   - つないだチャンネルに **室温（20〜30℃）** が出る
   - プローブを **指でつまむと温度が上がる**（下がったら＋−が逆）
   - 熱電対を外すと **1 秒以内に「断線」** と出る
   - つないでいないチャンネルを「使わない」にすると、表示が消える
4. シリアルモニタ（115200bps）でも、1 秒ごとの値（`{"type":"s",...}`）と、起動時の AP の名前とパスワード（`{"type":"wifi",...}`）を見られます

LED の意味: 速い点滅 = 家の Wi-Fi に接続中 / ゆっくり点滅 = 機器自身の Wi-Fi（AP）で待機中 / 点灯 = 家の Wi-Fi に接続済み / 2 回点滅の繰り返し = 熱電対の故障あり / 3 秒の高速点滅 = アプリの「機器を光らせる」
押しボタンを **5 秒長押し** すると、家の Wi-Fi の設定を消して、機器自身の Wi-Fi（AP）で起動し直します。
