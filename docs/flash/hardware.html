温度計の組み立て（配線・はんだ付け・熱電対）

焙煎記録ノートの温度計は、XIAO ESP32C3（マイコン）と、熱電対の温度アンプ基板を 1〜3 枚つないで作ります。 アンプは MAX31855（Adafruit #269 または互換品）が試作の標準です。MAX31856（Adafruit #3263）でも作れます（後半に配線を載せます）。

  • 熱電対は K 型を 1〜3 本。太さ・長さ・差し込む位置は使う人が決めます。ファームもアプリもそれに依存しません
  • ファームの書き込みは、パソコンの Chrome で docs/flash/index.html（公開ページ）を開いて「書き込む」を押すだけです。Wi-Fi の設定も、同じ画面の「Wi-Fi を設定」でできます
  • 電源（USB）を入れる前に、必ず「3.1 電源を入れる前の確認」をしてください

1.1 XIAO の外付けアンテナ（U.FL）を付ける — 付けないと Wi-Fi がほぼ届きません

XIAO ESP32C3 には基板上のアンテナがありません。基板の端にある小さな丸い（四角い）金色の端子（U.FL コネクタ）に、付属の細い線つきアンテナをつなぎます。 アンテナを付けないと、同じ部屋の中でも Wi-Fi がほとんど届かず、「RoastLog-XXXX が見つからない」「すぐ切れる」になります。

  1. USB を抜いた状態で作業します（電源を入れたまま付けない）
  2. 箱に入っている細い線の先に小さな金属の丸い金具が付いたアンテナを出します。XIAO の USB-C コネクタのそばに、U.FL コネクタ（直径 2mm ほどの小さな金色の丸い端子）があります
  3. アンテナの金具の穴を、コネクタの真上にまっすぐ合わせます（斜めにしない）
  4. 指先（またはピンセットの背）で、金具の真上から「カチッ」と音がするまで押し込みます。力は軽くでかまいません。ぐらつかなければ付いています
  5. 付けたら、線を軽く引いて抜けないか確かめます（抜けるのは、はまっていないということです。もう一度押し込みます）
  6. アンテナの本体（板や棒の部分）は、金属の近く（焙煎機・手網・ボウルなど）を避けて、貼り付けるか、ケースの外にたらします。炎や熱から離してください
  7. 外すときは、線を引っ張らないでください（コネクタが壊れます）。金具の端に細いマイナスドライバーなどの先を入れて、真上に持ち上げます

互換モジュールや偽物の注意は 2.3 を見てください。

2. 配線（MAX31855 版・標準）

3 枚のアンプは SPI のクロック（CLK）とデータ（DO）を共有し、CS（チップ選択）だけを 1 枚ずつ別の線にします。 MAX31855 は読み取り専用なので MOSI（D10）は使いません。

  • 熱電対が 1 本なら #1 だけ、2 本なら #1 と #2 をつなぎます。使わない CS の線はつながなくてかまいません
  • MISO は D7（GPIO20）です。D9（GPIO9）ではありません。 GPIO9 は XIAO の BOOT ボタンと同じ線で、起動のときに Low だと「書き込みモード」で止まってしまうため、アンプの DO をつなぎません。D9 には何もつなぎません
  • GPIO20 は本来「UART の受信（RX）」のピンですが、この機器は USB 経由（USB CDC）でシリアルをやりとりするので、使ってかまいません
  • 電源は 3V3 から取ります。XIAO の 5V 端子にはつなぎません。
    • Adafruit #269 は基板にレギュレータがあり、Vin に 5V を入れても、チップは 3.3V で動いて DO は 3.3V のままです（#269 では「5V にすると DO が 5V になる」は誤りです）
    • 互換基板はレギュレータが無いものがあり、そういう基板は Vin に 5V を入れると DO も 5V になり、XIAO を傷めます（XIAO の入出力は 3.3V までです）。互換基板では、必ず 3V3 から取ってください
    • どちらの基板でも 3V3 から取れば安全なので、迷ったら 3V3 にします
  • 各 CS に 10kΩ のプルアップ（CS と 3V3 のあいだに 10kΩ）は任意です。 付けなくても動きます。付けると、起動の直後や配線が外れたときに、アンプが勝手に DO を出してしまうのを防げて、より安定します。1 枚ずつ、CS の線と 3V3 の列のあいだに 1 本ずつ入れます
  • 外付けのボタン（D5）は、Wi-Fi の設定のリセット（5 秒長押し）と、Wi-Fi の設定の受付（短く押す。7.2）に使います

2.3 互換モジュール（Amazon などの安い MAX31855 基板）の注意

  • 3.3V で動くかを必ず確かめる。基板にレギュレータが載っていて「Vin 3〜5V」と書いてあるもの、または「3.3V 動作」と書いてあるものを選ぶ。5V 専用の基板は使えない
  • ピンの名前が SO（= DO）、SCK（= CLK）、VCC（= Vin）のように違うことがある
  • 偽物の MAX31855 が出回っています。届いたら、まず熱電対をつながずに電源を入れ、診断画面で 「断線」（OC） と表示されること、熱電対をつないで 室温（20〜30℃） が出ることを確かめてください。どちらかがおかしければ使わない
  • 熱電対の線を差し込む端子が T+ T− ではなく + − だけのことがある
  • 互換基板は、レギュレータが無く、Vin に 5V を入れると DO が 5V になるものがあります（2.1）。3V3 から取ってください

2.4 電源を入れる前の確認（必ず）

配線やはんだ付けのあとは、USB をつなぐ前に、次を確かめます。ここで見つかる失敗は、ほとんどが「はんだのつながり（ブリッジ）」か「線の差し間違い」です。

  1. USB ケーブルが抜けていることを確かめる
  2. テスターを導通（ブザー）にして、XIAO の 3V3 の穴と GND の穴に棒を当てる
    • 鳴らない（OL・抵抗が大きい）ならよい。ピーッと鳴る（0Ω に近い）なら、3V3 と GND がショートしています。電源を入れないでください。はんだのブリッジ、ジャンパ線の差し間違い、ブレッドボードの列の間違いを探して直します
    • 抵抗モードなら、3V3−GND は数百Ω〜数kΩ以上（コンデンサの充電で最初は低く見えて、だんだん上がることがあります）。1Ω 未満はショートです
  3. 各アンプの Vin と GND のあいだも同じように測る（鳴らなければよい）
  4. 3V3 と、D7 / D8 / D1 / D2 / D3 / D4 / D5 のあいだが、つながっていない（鳴らない）ことを確かめる
  5. はんだ付けした部分を、明るいところで目で見て、となりのピンと銀色の橋でつながっていないことを確かめる（4 章）
  6. 全部よければ USB をつなぎ、30 秒以内に LED が点滅し、基板が熱くなっていないことを確かめる（指でそっと触れる）。熱い・においがする・LED がつかないときは、すぐ USB を抜く

4. はんだ付け（初めての人向け）

アンプ基板と XIAO には、ピンヘッダ（足）を自分で付ける必要があります。Adafruit #269 は、ネジ端子（熱電対をつなぐ青い 2 ピンのブロック）も自分ではんだ付けします（袋に入っていて、基板には付いていません）。互換基板も、端子やピンが付いていないものが多いです。

4.1 はんだ付けの安全（先に読んでください）

  • 換気する: 窓を開けるか、換気扇を回します。はんだの煙（フラックス）は吸い込まないでください。顔を煙の真上に近づけないこと
  • やけど: こて先は 300℃以上になります。こて台に置くこと。机や手に直接置かない。作業の途中でその場を離れない。終わったら必ず電源を切り、コンセントを抜いて、完全に冷めるまで（20 分ほど）さわらない
  • 熱くなったはんだや、はじけたはんだ（飛び散り）が目に入らないよう、保護メガネがあると安心です
  • 手を洗う: 作業が終わったら、必ず手を洗ってください。糸はんだには鉛が入っているものがあり、手についたまま飲食すると口に入ります。作業中は飲食しない。鉛フリーのはんだでも、フラックスは手を洗って落とします
  • はんだの切りくず・はんだ吸取線・使ったはんだは、小さな子どもやペットの手の届かない所に置き、燃えるごみにしない（自治体の指示に従う）
  • こて先が汚れたら、濡らしたスポンジか真ちゅうのたわしでふいて、新しいはんだを少し乗せてから使います

4.2 手順

  1. こての温度は 340℃ くらいにします（鉛フリーはんだなら 350〜370℃）。熱すぎると基板のパターンがはがれます
  2. ピンヘッダをブレッドボードに差してから、その上に基板を載せて付けます。これでピンがまっすぐに立ちます（長い方の足をブレッドボードに差す）
  3. まず 両端の 2 本だけ 付けて、基板が傾いていないか見ます。傾いていたら、そのピンを温め直してまっすぐにします
  4. 残りのピンを付けます。こて先をピンと基板の穴（ランド）の両方に 1〜2 秒当ててから、はんだを当てて溶かし、はんだが流れたらはんだ → こての順に離します。全部で 3〜4 秒が目安
  5. できあがりは 富士山のような形（ピンのまわりに円すい状に広がり、つやがある）。丸い玉になっていたら温め直します
  6. 最後に ブリッジ（となりのピンとはんだがつながっている） がないか、明るいところで横から見て確かめます。つながっていたら、はんだ吸取線を当てて上からこてで温めて吸い取ります
  7. ネジ端子（Adafruit #269）も、ピンと同じようにはんだ付けします。 端子を基板の穴に差して（ネジ穴の口が基板の外側に向くように）、基板を裏返して支え、2 本の足をそれぞれはんだ付けします。付けずに熱電対を押し当てても、接触しないので温度が出ません（「断線」になります）。付けたあと、端子を軽く揺らして、ぐらつかないことを確かめます
  8. はんだ付けが終わったら、手を洗い、2.4 の「電源を入れる前の確認」をしてから USB をつなぎます

5. 熱電対

5.1 非接地型を使う（MAX31855 では必須）

熱電対の先端（2 本の線を溶接した点）が、金属のさや（シース）とつながっていないものを「非接地型」と言います。

  • MAX31855 は、熱電対の線が GND（金属のドラムや手網の網など、アースにつながった金属）に触れると 「GND 短絡」（SCG） の故障になったり、値が飛んだりします
  • 先端の線がむき出しの熱電対は、先端が金属（ドラム・網・ヒーター）に触れないように取り付けてください
  • テスターで確かめる方法: テスターを導通（ブザー）か抵抗（Ω）にして、片方の棒をシース（金属のさや）、もう片方を熱電対の線の片方に当てます。もう片方の線でも同じようにします
    • どちらの線でも 鳴らない（抵抗が無限大＝OL） → 非接地型。使えます
    • 鳴る（数Ω） → 接地型。MAX31855 では使えません（MAX31856 なら動くことが多いですが、おすすめはしません）
    • 2 本の線どうしは、つながっている（数Ω〜数十Ω）のが正常です。つながっていなければ断線しています

5.2 線の色と＋−（つなぐ向き）

熱電対の線の色は、規格によって違います。逆につなぐと、温度が上がると表示が下がります。

規格＋（クロメル）−（アルメル）
ANSI（アメリカ。Amazon の安い品に多い）黄赤
JIS（日本の旧色）赤白
IEC（国際・日本の新色）緑白
  • 「赤」が ANSI ではマイナス、JIS ではプラスです。色だけで決めないでください
  • 磁石で確かめる方法: K 型の − 側（アルメル）は磁石に付きます。＋側（クロメル）は付きません。冷蔵庫の磁石などを近づけてみてください
  • アンプのネジ端子の ＋ にクロメル（磁石に付かない方）、− にアルメル（磁石に付く方）をつなぎます
  • アプリの診断画面で確かめられます: プローブの先を指でつまむと、温度が上がれば正しい向きです。下がったら＋−が逆なので入れ替えてください。熱電対を外すと「断線」と出ることも確かめられます

6. 安全上の注意

  • 本体（XIAO・アンプ基板・ブレッドボード・USB ケーブル）は炎や焙煎機の熱から離して置いてください。熱に耐えるのは熱電対の先（シース）と耐熱の線だけです。基板は 85℃を超えると壊れたり、温度がずれたりします（「基板温度異常」と表示されます）
  • 熱電対の線のうち、耐熱の被覆（ガラス繊維など）でない部分を火に近づけないでください
  • 手網で使うときは、振っても線が引っ張られないように、線に余裕を持たせて固定してください
  • 焙煎中は電源（USB）を抜かないでください。抜いてもアプリ側の記録は残りますが、抜いている間の温度は記録されません
  • 外付けアンテナも、炎・熱・金属から離してください（Wi-Fi が弱くなります）
  • 子どもの手の届かない場所で使ってください

7. 組み立てたあとの確認（診断画面）と Wi-Fi の設定

7.1 書き込みと確認

  1. 2.4 の「電源を入れる前の確認」をする
  2. 書き込みページでファームを書き込む（docs/flash/）。書き込みは設定の領域（Wi-Fi・補正値）を消しません
  3. 書き込みが終わった画面の 「Wi-Fi を設定」 で、家の Wi-Fi を設定する（7.2）。または、スマホを RoastLog-XXXX の Wi-Fi につなぎ、http://192.168.4.1 を開く
  4. 機器の診断画面で:
    • つないだチャンネルに 室温（20〜30℃） が出る
    • プローブを 指でつまむと温度が上がる（下がったら＋−が逆）
    • 熱電対を外すと 1 秒以内に「断線」 と出る
    • つないでいないチャンネルを「使わない」にすると、表示が消える（アンプが 1 本のときは、初めから「使わない」になっています）
  5. シリアルモニタ（115200bps。書き込みページの 「ログとコンソール」、または pio device monitor）でも、1 秒ごとの値（{"type":"s",...}）、起動時の AP の名前とパスワード（{"type":"wifi",...}）、10 秒ごとの状態（{"type":"st",...}。電波の強さ rssi と空きメモリ heap / heapMax）を見られます

7.2 Wi-Fi の設定のしかた

やりかたいつ手順
書き込みページの「Wi-Fi を設定」（Improv Serial。本命）パソコンにつないだとき書き込みページ（Chrome）→「書き込む」→ 機器を選んで接続 →「Wi-Fi を設定」→ 家の Wi-Fi の名前とパスワードを入れる。つながると機器のアドレスが出て、「Visit Device」で開ける
機器自身の Wi-Fi（AP）からパソコンがないときスマホで RoastLog-XXXX（パスワードは機器のラベル、または「ログとコンソール」の表示）につなぎ、http://192.168.4.1/wifi を開く。家の Wi-Fi を選んで保存
すでに家の Wi-Fi につながっている機器の設定を変える引っ越し・ルーター交換機器のボタンを短く押す（LED が 0.25 秒おきに点滅）。そこから 60 秒以内に、スマホで http://roast.local/wifi を開いて設定する。それ以外のときは、STA 状態の機器は設定を受け付けません
全部やり直すうまくいかないときボタンを 5 秒長押し すると、家の Wi-Fi の設定を消して、機器自身の Wi-Fi（AP）で起動し直します
  • AP の名前とパスワードは、AP のあいだ 10 秒ごとに、シリアル（「ログとコンソール」）に出ます（ラベルを無くしても読めます）
  • 家の Wi-Fi が一時的に見つからなくて AP になったときは、クライアントがつながっていなければ 1 分ごとに家の Wi-Fi へのつなぎ直しを試みます。見つかれば自動で STA にもどります
  • Wi-Fi のパスワードは 8 文字以上（WPA2 の決まり）。鍵のない Wi-Fi は空にします
  • 他のサイトのページから機器の設定を書き換えられないよう、設定の受付は「機器から開いたページ」からの JSON だけです

7.3 LED と動作

LED の意味: 速い点滅 = 家の Wi-Fi に接続中 / ゆっくり点滅 = 機器自身の Wi-Fi（AP）で待機中 / 点灯 = 家の Wi-Fi に接続済み / 2 回点滅の繰り返し = 熱電対の故障あり / 3 秒の高速点滅 = アプリの「機器を光らせる」/ 少し速い点滅（0.25 秒おき）= Wi-Fi の設定を受け付け中（ボタンを短く押したあとの 60 秒） 押しボタンを 5 秒長押し すると、家の Wi-Fi の設定を消して、機器自身の Wi-Fi（AP）で起動し直します。

7.4 この機器の更新について

ファームを更新するときは、書き込みページからもう一度書き込みます（/update（無線での更新）はありません。/api/info に "ota": false と出ます）。設定とアプリの記録（スマホ側）は消えません。

付録 実機試験チェックリスト

部品が届いて組み立てたあとに、1 つずつ確かめる表です。上から順にやってください（前の項目が通らないと、次はやる意味がありません）。 結果は「○（できた）／×（だめだった）」と、気づいたことをメモしておきます。×のときは、その項目の「だめなとき」を見て、それでもだめなら、症状（シリアルの表示を含む）を報告してください。

準備

  • パソコン（Chrome か Edge）、書き込みページ、USB-C ケーブル、スマホ、テスター
  • シリアルの見かた: 書き込みページで「書き込む」を押し、機器を選んで接続 →「ログとコンソール」を開く（115200bps）。1 秒ごとに {"type":"s",...} が流れます
  • 熱電対（できれば 2 本）、氷水（コップに氷と水）、お湯

T1 電源を入れる前（ショートがない）

  • やること: USB を抜いた状態で、2.4 の 1〜5 をやる（3V3−GND のテスター確認、目視）
  • 期待: 3V3−GND が導通しない（ブザーが鳴らない）。ブリッジが無い
  • だめなとき: 電源を入れない。はんだ付けをやり直す（4 章）

T2 外付けアンテナ

  • やること: アンテナを付ける（1.1）。付けた状態で、機器から 5m ほど離れた所でスマホの Wi-Fi 一覧に RoastLog-XXXX が出るか見る。可能なら、アンテナを外した状態（USB を抜いて作業）と比べる
  • 期待: アンテナありで見つかる。シリアルの {"type":"st",...,"rssi":-60} のように、機器が家の Wi-Fi につながっているとき rssi が -70 より大きい（0 に近い）
  • だめなとき: アンテナをもう一度「カチッ」と押し込む。金属から離す

T3 書き込みと起動

  • やること: 書き込みページで書き込む（アンプは MAX31855 か MAX31856 を選ぶ）。終わったら、「ログとコンソール」で起動の表示を見る
  • 期待: 最後まで終わる（途中で止まらない）。{"type":"boot",...} と {"type":"detect","present":[...]} が出る。接続しているアンプが true
  • だめなとき: BOOT ボタンを押したまま USB を挿し直して、もう一度書き込む

T4 再書き込みで設定が残る

  • やること: Wi-Fi を設定し（T7）、アプリで CH1 の補正値を 1.5 にする。そのあと、もう一度書き込みページで書き込む
  • 期待: 書き込んだあとも、家の Wi-Fi につながり、補正値が 1.5 のまま
  • だめなとき: 設定の領域（NVS）を書き換えている可能性。報告する

T5 3 本のアンプが読める（MISO = D7）

  • やること: 熱電対をつないで（アンプが 1〜3 枚）、アプリの診断画面（または {"type":"s"}）を見る。USB を挿し直す／RESET を押す、を 10 回くり返す。途中で XIAO の BOOT ボタンを押してみる
  • 期待: すべてのチャンネルに室温（20〜30℃）が出る。10 回とも起動する。BOOT ボタンを押しても読み取りは乱れない（D9 は使っていないので）
  • だめなとき: D7（MISO）の配線、各アンプの DO と CS を見直す。起動しない回があれば報告（10kΩ のプルアップを付けると改善することがあります）

T6 シリアルと USB の動作（GPIO20）

  • やること: 30 分ほど「ログとコンソール」をつないだままにする。USB を抜き差ししたあと、もう一度書き込みページから書き込む
  • 期待: ログが途切れない。USB を抜き差ししても接続できる。再書き込みもできる
  • だめなとき: 報告（GPIO20 と USB CDC の干渉の可能性）

T7 書き込みページから Wi-Fi を設定（Improv）

  • やること: 書き込みの画面（または「書き込む」→ 接続）で「Wi-Fi を設定」を押し、家の Wi-Fi を入れる。わざと間違ったパスワードも 1 回試す
  • 期待: 正しい設定なら、機器のアドレスが出て、「Visit Device」でアプリが開く（LED が点灯）。間違ったパスワードなら、エラーが出て、もとの画面にもどる（機器は AP のまま）
  • だめなとき: 「ログとコンソール」の表示を添えて報告。手動で http://192.168.4.1/wifi から設定もできる

T8 AP 名とパスワードの表示

  • やること: Wi-Fi を設定していない（または ボタン 5 秒長押しで消した）機器で、「ログとコンソール」を 1 分見る
  • 期待: 10 秒ごとに {"type":"wifi","apSsid":"RoastLog-XXXX","apPass":"…",…} が出る。その名前とパスワードでスマホがつながる
  • だめなとき: 報告

T9 Wi-Fi 設定の受付の制限

  • やること:
    • 家の Wi-Fi につながっている状態で、パソコンから curl -i -X POST -H 'Content-Type: application/json' -d '{"ssid":"x","pass":"12345678"}' http://roast.local/api/wifi（または機器の IP）を実行する → 403（受け付けない）
    • 機器のボタンを短く押す（LED が 0.25 秒おきに点滅）→ 60 秒以内に同じコマンド → 200 になり、機器が再起動する。実行すると Wi-Fi の設定が書き換わるので、ssid と pass は、家の Wi-Fi の本当の名前とパスワードにしておく
    • 60 秒後にもう一度 → 403
    • もう一度ボタンを短く押して、受付中のあいだに: Content-Type を付けずに送る → 415。パスワードを 7 文字にする → 400。2KB の本文 → 413（1 回だけ）。空の本文 → 400
  • 期待: 上のとおり
  • だめなとき: 報告（コマンドと返ってきた内容を添える）

T10 家の Wi-Fi が戻ったら自動でつなぎ直す

  • やること: 家のルーターを切って機器を起動する（20 秒後に AP になる）。そのまま、ルーターを入れ直す。スマホは機器につながない
  • 期待: 最大 1〜2 分で、機器が家の Wi-Fi につながる（LED が点灯。「ログとコンソール」で mode が ap_sta か sta になる）
  • だめなとき: 報告。スマホを機器の AP につないでいると試さない仕様（つなぎ直しは、クライアントがいないときだけ）

T11 複数の端末と、つなぎ直し

  • やること: スマホ 2 台とパソコンで同時にアプリを開く（3 台）。もう 1 台（合計 4 台）、さらに 5 台目を開く。タブを閉じる・開くを 50 回くり返す。機内モードを入れて切る
  • 期待: 4 台まで見られる。5 台目は接続できない（またはすぐ切れる）。閉じたあと、また 4 台まで入れる（枠が減らない）。数分後も、st の clients が実際の台数と合う
  • だめなとき: 報告（clients が増えたままになる場合は、B5 の再発）

T12 長時間（30 分）とメモリ

  • やること: 熱電対をつないで、アプリを 1 台開いたまま 30 分動かす。「ログとコンソール」の st の heap と heapMax をメモする（最初と最後）
  • 期待: heap がじわじわ減り続けない（最初と最後で、ほぼ同じ）。heapMax が 40000 より大きい。リセットしない（uptime が増え続ける）
  • だめなとき: 値を報告

T13 遅れた分の追いつき（バックグラウンド）

  • やること: スマホでアプリを開いて焙煎の画面にし、ホームに戻って 5 分放置する（画面を消す）。そのあとアプリにもどる。続けて、2 台目でも同じことをする
  • 期待: 5 分の欠けが埋まる（グラフに穴がない）。その間、heapMax が落ち込まない。機器が再起動しない
  • だめなとき: 報告（st の heapMax の値を添える）

T14 アンプ 1 枚だけの初回起動

  • やること: アンプ 1 枚だけつないで、設定が空の機器（ボタン 5 秒長押しは Wi-Fi だけ消すので、新しい機器、または別の XIAO）で起動する
  • 期待: 診断画面に CH1 だけが出る。CH2・CH3 は「使わない」で、故障の表示が出ない。LED が 2 回点滅にならない。熱電対を外すと、CH1 だけが「断線」になる
  • だめなとき: 報告（{"type":"detect",...} の表示を添える）

T15 MAX31855 の検出（断線・短絡・更新停止）

  • やること: ① 熱電対を外す／つなぐ ② 熱電対の先を氷水に入れて 1 分以上動かさない ③ 30 分連続運転
  • 期待: ① 1 秒以内に断線（外す）→ 戻る（つなぐ）。② 氷水で温度が安定しても、故障（更新停止）が出ない（生の値が 20 秒以上まったく変わらないと出る設計です。0.25℃ 刻みなので、安定しすぎると出る可能性があります）。③ 誤って故障が出ない
  • だめなとき: 氷水で「更新停止」が出たら、報告（しきい値 MAX31855_STALE_READS の調整が必要）

T16 MAX31856 の 50/60Hz とノイズ

  • （MAX31856 版だけ）
  • やること: アプリの設定で 50Hz → 60Hz → 50Hz と切り替える。切り替えるたびに「ログとコンソール」の {"type":"diag",...,"verified":true,...} を見る。モーターや炎の近くで、読み取りの揺れ（ノイズ）を見る
  • 期待: 切り替えのあと、verified が true。切り替え中も読み取りが止まらない（数秒以内に再開）。電源の周波数に合う方（東日本 50Hz／西日本 60Hz）のほうが、値の揺れが小さい
  • だめなとき: 報告（diag の表示を添える）

付録 ESP32 DevKit・DevKitM-1 について

  • env:esp32dev（ESP32 DevKitC）は、手持ちの DevKit 用です。ピンは firmware/include/pins.h のとおり（SCK=18、MISO=19、MOSI=23、CS=5/17/16）。書き込みページにも載せています
  • env:esp32c3_devkit（ESP32-C3-DevKitM-1）は、ビルドが通ることだけ確かめていて、実機では確かめていません。書き込みページにも載せていません。LED を GPIO8（起動モードを決めるピンで、基板の RGB LED のデータ線）につないでいるなど、実機で使う前に見直しが要ります
