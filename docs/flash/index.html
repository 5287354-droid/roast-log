温度計に書き込む

焙煎記録ノートの温度計（ESP32）に、ファームウェアとアプリをまとめて書き込みます。USB ケーブル 1 本と、パソコンの Chrome があればできます。

このブラウザでは書き込めません。
パソコン（Windows / Mac / Linux）の Google Chrome か Microsoft Edge で、このページを開いてください。スマホや Safari・Firefox は使えません。

1. 使うアンプを選ぶ

温度アンプ（基板）

ボード（XIAO ESP32C3 / ESP32 DevKit）は、つないだときに自動で見分けます。

2. 機器をパソコンにつなぐ

  1. データ通信ができる USB-C ケーブルを用意します（充電専用のケーブルでは認識しません）。
  2. XIAO ESP32C3 の場合: 基板の B（BOOT）ボタンを押したまま USB ケーブルを挿し、挿したらボタンを離します。
    はじめて書き込むときや、うまく認識しないときに必要です。2 回目以降は押さなくても書けることが多いです。
  3. ESP32 DevKit の場合: そのまま挿します。うまくいかないときは BOOT を押しながら書き込みを始めてください。
  4. Windows で機器が出てこないときは、USB シリアルのドライバ（CP210x / CH340）を入れてください。XIAO ESP32C3 はドライバ不要です。

3. 書き込む

このページは https で開く必要があります。

  1. 「書き込む」を押すと、接続先を選ぶ窓が出ます。USB JTAG/serial debug unit（XIAO）や CP2102 / USB Serial（DevKit）を選んで「接続」。
  2. 「INSTALL（インストール）」を押します。「消去してから書き込む」にチェックを入れると、Wi-Fi の設定もまっさらになります（はじめてならチェック推奨）。
  3. 1〜2 分で終わります。終わるまでケーブルを抜かないでください。
  4. 終わったら、XIAO の R（RESET）ボタンを押すか、USB を挿し直してください。

4. 書き込んだあと

  1. スマホの Wi-Fi 設定に RoastLog-XXXX が出てきます。つなぐときのパスワードは、機器のラベルに書いてある 8 桁の数字です（ラベルが無いときは、パソコンでシリアルモニタを開くと起動時に表示されます）。
  2. つないだら、Safari / Chrome で http://192.168.4.1 を開きます。焙煎記録ノートが出れば成功です。
  3. 家の Wi-Fi につなぎたいときは http://192.168.4.1/wifi で設定すると、以後は http://roast.local で開けます。
うまくいかないとき
  • 接続先の窓に何も出ない → ケーブルを替える／BOOT ボタンを押しながら挿し直す。
  • 「Failed to connect」 → BOOT を押したまま挿し直してから、もう一度「書き込む」。
  • 書き込んだのにアプリが出ない → 「消去してから書き込む」にチェックを入れて、もう一度書き込む。
安全のために
  • 温度計の本体（基板・ケーブル）は、焙煎機や火から離して置いてください。熱くなるのは熱電対の先だけです。
  • 熱電対の線の色と＋−の見分け方は、配線の説明（docs/HARDWARE.md）を見てください。
