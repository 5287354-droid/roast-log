温度計に書き込む

焙煎記録ノートの温度計（ESP32）に、ファームウェアとアプリをまとめて書き込みます。USB ケーブル 1 本と、パソコンの Chrome があればできます。

このブラウザでは書き込めません。
パソコン（Windows / Mac / Linux）の Google Chrome か Microsoft Edge で、このページを開いてください。スマホや Safari・Firefox は使えません。

1. 使うアンプを選ぶ

温度アンプ（基板）

ボード（XIAO ESP32C3 / ESP32 DevKit）は、つないだときに自動で見分けます。

2. 機器をパソコンにつなぐ

  1. データ通信ができる USB-C ケーブルを用意します（充電専用のケーブルでは認識しません）。
  2. XIAO ESP32C3 の場合: 基板の B（BOOT）ボタンを押したまま USB ケーブルを挿し、挿したらボタンを離します。
    はじめて書き込むときや、うまく認識しないときに必要です。2 回目以降は押さなくても書けることが多いです。
  3. ESP32 DevKit の場合: そのまま挿します。うまくいかないときは BOOT を押しながら書き込みを始めてください。
  4. Windows で機器が出てこないときは、USB シリアルのドライバ（CP210x / CH340）を入れてください。XIAO ESP32C3 はドライバ不要です。

3. 書き込む

このページは https で開く必要があります。

  1. 「書き込む」を押すと、接続先を選ぶ窓が出ます。USB JTAG/serial debug unit（XIAO）や CP2102 / USB Serial（DevKit）を選んで「接続」。
  2. 「INSTALL（インストール）」を押します。
  3. 1〜2 分で終わります。終わるまでケーブルを抜かないでください。
  4. 終わると、そのまま次の画面（Wi-Fi の設定）が出ます。出なければ、XIAO の R（RESET）ボタンを押すか USB を挿し直してから、もう一度「書き込む」を押して接続してください。

この書き込みでは、機器の中の Wi-Fi の設定や補正値は消えません（設定の領域には書き込みません）。Wi-Fi の設定だけを消したいときは、機器のボタンを 5 秒長押ししてください。

4. Wi-Fi を設定する（パソコンから）

書き込みが終わった画面に、機器の名前と 「Wi-Fi を設定」 のボタンが出ます。ここから家の Wi-Fi をそのまま設定できます（Improv Serial）。

  1. 「Wi-Fi を設定」を押し、家の Wi-Fi の名前を選んで（出ないときは名前を入力）、パスワードを入れて「接続」。
  2. つながると、機器のアドレス（http://192.168.…）が出ます。「Visit Device（機器を開く）」を押すと、焙煎記録ノートが開きます。以後はスマホから http://roast.local でも開けます。
  3. つながらなかった（パスワード違い・電波が弱い）ときは、エラーが出てもとの画面にもどります。もう一度入れ直してください。

うまくいくと、機器は家の Wi-Fi につながります（LED が点灯）。書き込みの画面を閉じたあとでも、書き込みページを開いて「書き込む」→ 接続すれば、「Wi-Fi を設定」をいつでもやり直せます。

5. 機器自身の Wi-Fi（RoastLog-XXXX）を使うとき

家の Wi-Fi を設定しなくても、機器自身の Wi-Fi で使えます。

  1. スマホの Wi-Fi 設定に RoastLog-XXXX が出てきます。つなぐときのパスワードは、機器のラベルに書いてある 8 桁の数字です。
  2. ラベルが無いときは、この画面の 「ログとコンソール」（書き込みの画面のボタン）を開いてください。機器が 10 秒ごとに、Wi-Fi の名前とパスワードを次の形で表示します。
    {"type":"wifi","apSsid":"RoastLog-XXXX","apPass":"12345678",…}
  3. つないだら、Safari / Chrome で http://192.168.4.1 を開きます。焙煎記録ノートが出れば成功です。
うまくいかないとき
  • 接続先の窓に何も出ない → ケーブルを替える／BOOT ボタンを押しながら挿し直す。
  • 「Failed to connect」 → BOOT を押したまま挿し直してから、もう一度「書き込む」。
  • 書き込んだのにアプリが出ない → もう一度書き込んでください（設定は残ります）。
  • Wi-Fi が全然見つからない（XIAO）→ 付属の外付けアンテナ（U.FL）を付けましたか。付けないと Wi-Fi がほとんど届きません。取り付け方は組み立て手順にあります。
  • 家の Wi-Fi の設定を消してやり直したい → 機器のボタンを 5 秒長押し（機器自身の Wi-Fi で起動し直します）。
安全のために
  • 温度計の本体（基板・ケーブル）は、焙煎機や火から離して置いてください。熱くなるのは熱電対の先だけです。
  • 配線・はんだ付け・熱電対の線の色と＋−の見分け方は、組み立て手順（HARDWARE）を見てください。
